## Overview
This project uses the **Sleep Health & Lifestyle Dataset** to predict whether an individual has **No Sleep Disorder**, **Insomnia**, or **Sleep Apnea** based on lifestyle and health indicators. Both supervised and unsupervised learning methods are applied to analyze patterns and risk factors associated with sleep disorders.

---

## Goal
😴 Predict sleep disorder category using demographic, lifestyle, and physiological features such as age, BMI, heart rate, and activity level.

---

## Programming Language
- **Python**

---

## Dataset
- **Source:** Kaggle – Sleep Health & Lifestyle Dataset  
- **Access Method:** Kaggle API via `kagglehub`  

The dataset is downloaded programmatically using the Kaggle API and loaded into Python for preprocessing and analysis.

---

## Models Used
- **K-Means Clustering** (Unsupervised)  
- **K-Nearest Neighbors (KNN)**  
- **Logistic Regression**  
- **Naïve Bayes**  
- **Decision Tree Classifier**
